# 彼女の見た目（キャラクター）を差し替える仕組み

1人の見た目＝1つのフォルダ。フォルダを入れ替えると、顔と動きの動画がまるごと入れ替わる。

```
persona/characters/<キャラ名>/
  character.md     … 名前・見た目の説明・身長・元の画像の出どころ（実在しない人であること）・権利
  reference.png    … 顔の元画像（AI で作った実在しない人物だけ。実在の人の写真は入れない）
  clips/           … 黒背景の動画（idle / walk / wave / talk / lean_in / read / dance / pose .mp4）
```

## 今使っているキャラ
- **Yori（作者の個人のキャラ・非公開）**。動画は作者の PC の `Assets/Companion/Clips/` にだけあり、公開リポには仮の人影（PLACEHOLDER）の動画が入っている（git は skip-worktree で本物を記録しない）。デモ動画で見られる。

## 新しいキャラを足す手順（将来）
1. 上の形でフォルダを作る（動画は黒背景・全身・正面寄り・MP4/H.264・1本10MB未満・縦横は16の倍数）。
2. `tools/build_persona.py --character <キャラ名>` で、動画を `Assets/Companion/Clips/` へ入れ替える。
3. Lens Studio で開き直すと、新しい見た目になる。

## 決まり
- 実在の人物の顔・有名人に似せた顔は使わない。
- 露出の多い服・性的な表現は入れない（公開の大会・ストアの決まり）。
- AI で作った動画は、使う前に 1秒3〜4コマで「腕・手の分裂／物が増える／顔が別人になる」を点検し、本人が目で見て OK を出す。
